Как обращаемся со спецификацией

  • Обезличенный формат. Работаем как расчёт по обезличенной спецификации (только партномера и количества, без имени вашего конечного заказчика).
  • Без чужих данных. Просим не включать чужие персональные данные и коммерческую тайну в загружаемый файл.
  • Без открытой почты. Вложения не пересылаются по открытой почте: файл сохраняется в закрытом хранилище, менеджер получает уведомление без вложения.
  • Автоудаление. Файлы удаляются автоматически по истечении срока хранения (retention) [срок утверждает заказчик].
  • NDA — по согласованию сторон, как опция, а не обязательное условие.
