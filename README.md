# Демо-сайт v4 — «Инженерный ЦОД-контур», светлая тема, демо-цены (48 позиций)

Кликабельный демо-прототип B2B-сайта поставок серверов, СХД, сетевого оборудования и ЗИП.
Собран по итогам выбора из трёх концепций v1: инженерная подача и плотная таблица ТТХ (из А) + тёмная палитра и информативность (из В).

> **Демо-прототип.** Цены — демонстрационные («от … ₽ с НДС на 27.11.2026»), **не оферта**; наличие и состояние — демо-значения для макета, без реальных остатков. Работаем «как с НДС» (ОСНО с нового года): цены с НДС 22 %, УПД. Формы работают в демо-режиме: данные никуда не отправляются. Телефон `+7 (495) 000-00-00` и e-mail `info@example.ru` — заглушки (в коде пометка `TODO`).

## Как открыть
- Двойной клик по `index.html` (работает по `file://`), или
- `python3 -m http.server 8080` в этой папке → http://localhost:8080/
- Внешних ресурсов нет: шрифты системные, иллюстрации — локальные SVG в `assets/img/`.

## Сценарий и сегменты
- Сценарий Б: полный каталог под холодный трафик — запуск после Go-Live Gate.
- Два стартовых сегмента: **01 / Системные интеграторы** и **02 / Операторы связи и ЦОД**. Значение `segment` в формах: `integrator | operator`.
- Страница «Для бизнеса»: реквизиты ООО «БИТ-ЛАБОРАТОРИЯ», «Работаем с НДС, УПД»; слоты проверки заказчика остаются только для каналов поставки (ГТД, нотификации ФСБ, ТР ТС) и таблицы гарантии продавца.

## Ключевые механики
- **Черновик спецификации (BOM)** — липкая нижняя панель: «+ В ТЗ» на любой позиции, −/+ количества, удаление; хранится в `localStorage` (`v3_bom_draft`). «Передать в расчёт ТЗ →» переносит таблицу `SKU | Модель | Состояние | Кол-во` в форму `rfq-spec.html` и в демо-payload (`bom_json`).
- Копирование SKU в один клик (тост-подтверждение).
- Только обезличенная спецификация; NDA — по запросу как опция.
- UTM / referrer / landing_page сохраняются в `sessionStorage` и попадают в payload; время — Europe/Moscow.
- Файлы ТЗ: PDF, XLS, XLSX, DOC, DOCX до 15 МБ. Файл между страницами не передаётся — подсказка просит прикрепить его в форме.

## Что нового в v4
- Светлое тело страниц, тёмные только шапка, подвал и панель ТЗ. Карточка: компактная иллюстрация слева, ключевые поля, цена и кнопки справа над сгибом.
- Расширенные ТТХ сетевых карточек: эталон — N9K-C93180YC-FX3 (по Cisco N9300-FX3 Data Sheet): варианты PE/PI и схема обдува, пропускная способность, буфер, MAC, память, потребление, комплектация, ссылка на datasheet. Для остальных позиций добавлена ссылка на документацию вендора (поле `datasheet`) и альтернативные партномера (`aliases`).
- Блок «Совместимые компоненты» (БП, вентиляторы, рейки, трансиверы, платформы) с «+ В ТЗ»; запчасти без карточки каталога попадают в ТЗ как виртуальные позиции (`part:<PN>`).
- Поиск по вариантам партномера: суффиксы `-PI/-PE/-RF`, «=», скобки и `#`, альтернативные номера (например, `866730-001`, `E810XXVDA2G1P5`); найденный по алиасу вариант подсвечивается в строке. На мобильном поиск — первый блок на первом экране.
- Сортировка по цене («Сначала дешевле / дороже»); заметная пометка «Демо-цена для макета, не оферта» в каталоге и на карточке.
- Убраны строка про 223-ФЗ / ПП № 1875 с первого экрана и все упоминания «оперативный склад / склад в Москве».
- Реквизиты и «Работаем с НДС, УПД» в подвале всех страниц и на «Для бизнеса».

## Демо-данные (v4)
48 реальных моделей с партномерами и ТТХ из открытых источников (см. `sources.md`): серверы 16, СХД 6, сеть и оптика 13, комплектующие и ЗИП 13. Вендоры: Dell, HPE, Lenovo, Huawei, xFusion, Supermicro, Cisco, NVIDIA, Arista, Broadcom, Seagate, Western Digital, Samsung, Intel.

- **Цены (демо, не оферта):** поля `price_amount` (₽, с НДС 22 %), `price_date` = 2026-11-27, `price_source` = `market` или `estimate`, `price_basis` (основание), `price_ref` (ссылка). **market — 13**, **estimate — 35**. `market` — нижняя найденная рыночная цена нового товара того же партномера; `estimate` — оценка (для восстановленного и б/у — коэффициент к рыночной цене нового: Factory 0,85, Seller 0,70, Б/у 0,55; для позиций без цены — экспертная оценка). Таблица — в `sources.md`.
- **Наличие и состояние — демо-значения для макета**: Новое 23, Factory Refurbished 6, Seller Refurbished 12, Б/у 7. Реальных остатков нет. Гарантия производителя для Seller Refurbished / Б/у не обещается.
- Для конфигурируемых платформ (Dell PowerEdge, xFusion, часть Huawei) единого публичного партномера нет: в SKU стоит идентификатор платформы, партномер собирается по ТЗ.
- Иллюстрации — локальные схематичные светлые SVG (`assets/img/l-*.svg`); фото и логотипы вендоров не используются.
- Все страницы закрыты от индексации: `<meta name="robots" content="noindex,nofollow">` и `robots.txt` с `Disallow: /`.
- Формы работают в демо-режиме, данные никуда не отправляются.
