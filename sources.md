# Источники ТТХ демо-каталога v3

Все ТТХ взяты из открытых источников (даташиты, спецификации, страницы вендоров, справочники партномеров), проверены 27.11.2026 (Берлин). Цены, наличие и состояние — демонстрационные значения для макета, в источниках их нет.

Партномер: где у платформы есть единый публичный партномер (HPE, Cisco, Huawei, Broadcom, накопители, память, карты), указан он. У конфигурируемых платформ (Dell PowerEdge, xFusion, часть Huawei) единого партномера нет — в поле SKU стоит идентификатор платформы, а партномер собирается по ТЗ.
